# SUPERMONKEY 门店 / 教室

通过 `sm-c-cli boxes` 查询 SUPERMONKEY 附近门店（教室）。当前提供一个 Shortcut：

- `+search`：根据**经纬度**查询附近的门店，可选按业态过滤。返回结果按距离正序排列。

## Shortcut：+search（查询附近门店）

```
sm-c-cli boxes +search --longitude <经度> --latitude <纬度> [--type class]
```

> 所有带空格 / 中文的参数值统一加双引号，避免 shell 把空格 / 中文截断。

参数：

- `--longitude`（**必填**）：经度。
- `--latitude`（**必填**）：纬度。
- `--type`（可选）：业态过滤，目前**仅支持 `class`**（团课）。
  - 用户明确表达「找团课教室 / 团课门店」时传 `--type class`。
  - 用户没明确说业态时**不要**传 `--type`，返回所有业态门店。

### 使用示例

按经纬度查询：

```
sm-c-cli boxes +search --longitude 121.45 --latitude 31.22
```

按经纬度 + 业态过滤：

```
sm-c-cli boxes +search --longitude 121.45 --latitude 31.22 --type class
```

### 返回字段

stdout 是 `{ code, data, msg }` 信封；成功时 `data.list` 是按距离**正序**排列的门店数组。向用户呈现每家门店时，至少包含以下字段：

| 字段            | 含义                                                            |
| --------------- | --------------------------------------------------------------- |
| `boxName`       | 门店名称                                                        |
| `city` / `area` | 城市 / 区域                                                     |
| `address`       | 详细地址                                                        |
| `distance`      | 距离用户的距离，已带单位（如 `"900m"` / `"1.2km"`），可直接展示 |
| `addressGuide`  | 到店指引链接（图文路线说明），有需要时给用户                    |
| `type`          | 业态（当前固定 `class`）                                        |

另外两个字段 `boxId` 和 `boxIdSk` 是给后续接口使用的内部标识，**不要展示给用户**。

## 参数推断指引

把用户的自然语言请求映射到 CLI 参数时遵循：

- **必须拿到经纬度**。`--longitude` 和 `--latitude` 都是必填，没有经纬度无法查询。
- **没有经纬度时，先引导用户发送当前位置**。**大多数 agent 聊天客户端**（飞书、企业微信、钉钉、各类 IM 等）原生支持发送位置消息，发送后 agent 可以直接拿到经纬度。当用户问"附近有什么门店 / 我周围哪里能上课"且当前对话里没有任何位置线索时，**第一反应是引导用户发送当前位置**，而不是直接追问"你在哪儿"。
- **位置必须明确**。如果用户既没发送位置、也拿不到经纬度，**先按上一条引导发送位置**，不要猜，也不要默认按某个城市查。
- **业态默认不过滤**。除非用户明确说「找团课教室 / 团课门店」，否则不要带 `--type`。当前白名单只有 `class`，传其他值会被拒绝。
- **结果已经按距离正序**。直接按返回顺序展示给用户即可，前 3 ~ 5 家通常就够用，不必重新排序。
- **distance 字段直接展示**。`data.list[].distance` 已经是 `"900m"` / `"1.2km"` 这种带单位的人类可读字符串，**不要**再做单位换算或数学加工。
- **按距离分层推荐**。展示门店时遵循以下优先级，**不要无差别铺一长串**：
  1. **优先推荐 3km 以内**的门店。
  2. 如果接口返回的 `data.list` 直接就是空数组，直接对用户说类似的话语：「抱歉，附近没有查询到超级猩猩门店，建议你换个位置再试，或前往超级猩猩官方小程序查看完整门店列表」。

## 输出契约

stdout 统一是 `{ code, data, msg }` 信封：

- 成功：`code === 0`，`data.list` 是按距离正序的门店数组（可能为空数组，表示该位置附近暂无门店，**不是错误**）。
- 失败：`code !== 0`，`msg` 是人类可读错误信息；同时 stderr 也会再写一份。

## 错误处理

- 信封里 `code !== 0` 即视为失败。把 `msg` 转述给用户，不要自行编造原因。
- 退出码非 0 时，先看 stdout 的信封 `msg`，再看 stderr 的补充信息。
- 参数错误（缺少 `--longitude` / `--latitude`、`--type` 非法值等）会以 `code: 40001` 返回，`msg` 已经包含具体哪个 flag 出错，直接告诉用户即可。
- **出现错误时如实报告给用户，不要假想 / 猜测 / 编造门店数据**。宁可告诉用户"查询失败"或"附近暂无门店"，也不要返回任何未经接口确认的门店信息或地址。
