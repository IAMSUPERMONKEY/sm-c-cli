# 超级猩猩业务覆盖城市

SUPERMONKEY（超级猩猩）目前**仅在以下 8 个城市**开展健身业务（开设线下门店 / 团课）：

- `北京市`
- `上海市`
- `广州市`
- `深圳市`
- `武汉市`
- `成都市`
- `南京市`
- `杭州市`

## 使用要点

- 这 8 个城市是**白名单**，不在此列的城市目前没有任何门店与课程，相关查询直接告知用户"该城市暂无门店"，不要发起请求。
- 城市名统一使用「\*\*市」格式（北京市 / 上海市 …）。用户只说「北京 / 上海 / 杭州」等省略「市」的写法时，自动补全为带「市」的形式后再使用。
- 直辖市（北京市、上海市）也按上述格式处理，不要写成「北京」「上海」。
