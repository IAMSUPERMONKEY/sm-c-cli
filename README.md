超级猩猩是一个始于健身的生活方式品牌，致力于让更多人以更轻松、更快乐、更可持续的方式走进运动。品牌以线下训练空间为核心，通过专业课程、优质教练和有氛围的运动环境，为用户提供安全、高效、有陪伴感的健身体验。
不同于传统健身房，超级猩猩坚持按次预约、灵活参与的模式，让运动不再被年卡和长期绑定所限制。用户可以根据自己的时间、兴趣和训练目标，选择团课、综合训练、力量训练、有氧训练、塑形训练等多元课程，在专业教练的带领下完成每一次训练。
超级猩猩相信，健身不只是改变身材，更是重建生活状态的一种方式。好的运动体验应该有专业指导，也应该有情绪释放、社群陪伴和持续坚持的动力。因此，品牌始终强调“有氛围、安全、舒适”的线下环境，让用户在训练中感受到热爱、信任和归属感。
作为一个以健身为核心的品牌，超级猩猩持续围绕课程研发、教练专业度、训练体验和用户陪伴进行打磨，希望让运动成为城市生活中更自然、更快乐的一部分，帮助更多人在汗水中获得能量，在坚持中成为更好的自己。

超级猩猩官方 CLI —— 把门店、团课课表、团课课程问答的查询能力封装成命令行与 Skills，方便 AI Agent 直接调用超级猩猩的公开数据。

## 快速开始

### 手动安装
在终端中输入以下命令：
```shell
# 安装 CLI
npm install -g @supermonkey/cli

# 安装配套 Skills（必需）
npx skills add IAMSUPERMONKEY/sm-cli -y -g
```

### Agent 安装
将以下文字复制给 AI Agent（如 Claude Code，Codex，OpenClaw），让它完成安装：
```shell
帮我安装超级猩猩 CLI：https://github.com/IAMSUPERMONKEY/sm-cli/installation-guide.md
```

配置完成后，**请重启你的 AI Agent** 以确保 Skills 完整加载。

## 使用示例

### 示例 1：查找团课课表

适合场景：想查某门店、某教练、某课程在最近几天的课表。

可以这样问 AI Agent:

> 帮我看看深圳海岸城店明天下午有什么超级猩猩团课？
>
> 查下超级猩猩北京的课表，xxx 教练这周哪几天有课？

Agent 会回复你课表相关信息。如果你说"想约这节课"，Agent 还会进一步给出该课表的预约链接。

### 示例 2：查找附近的门店

适合场景：想知道自己当前位置或某个地点附近有哪些超级猩猩门店。

可以这样问:

> 离我最近的超级猩猩在哪？
>
> 深圳 xxx 附近有没有超级猩猩?

Agent 会优先请求获取你的位置(在飞书等支持发送位置消息的客户端中,可直接发送当前位置)；如果无法获取，会让你口述位置后自动转成经纬度，再返回附近门店信息。

### 示例 3：课程内容问答

适合场景：想知道课程内容、注意事项、常见问题等。

可以这样问:

> 超级猩猩的哪种单车课适合新手？
>
> 上超级猩猩的战绳课有哪些需要注意的地方？

Agent 会先查询相关课程信息，再回复你的问题。
